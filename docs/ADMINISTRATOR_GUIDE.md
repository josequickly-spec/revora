# Administrator Guide

Administrators manage organizations, teams, roles, sessions, MFA, API keys, billing views, workflows and executive analytics.

- Require MFA for privileged users through organizational policy.
- Review active sessions and revoke unknown devices.
- Give API keys the smallest permission set and an expiration.
- Configure Stripe price IDs before enabling checkout.
- Run warehouse refresh through an authorized workflow operator.
- Treat forecasts as estimates, not commitments.
- Review executive recommendations before acknowledgement; recommendations never execute.
- Monitor dead-letter jobs, open alerts, failed warehouse runs and missing snapshots.
- Record secret rotations and backup/restore tests without storing secret material.

Owner access should be held by at least two controlled accounts. Do not share credentials or API keys.
