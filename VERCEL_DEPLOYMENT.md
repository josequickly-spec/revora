# Revora - Vercel Deployment Guide

## ✅ Prerequisites
- GitHub account
- Vercel account (free tier)
- API Keys ready:
  - OPENAI_API_KEY
  - HUNTER_API_KEY
  - RESEND_API_KEY

## 📋 Step 1: Push to GitHub

```bash
# Initialize GitHub repo (if not done)
git remote add origin https://github.com/YOUR_USERNAME/revora.git
git branch -M main
git push -u origin main
```

## 🚀 Step 2: Deploy on Vercel

1. Go to https://vercel.com
2. Click "New Project"
3. Connect GitHub account
4. Select "revora" repository
5. Configure Build Settings:
   - Framework: Next.js
   - Build Command: `npm run build`
   - Output Directory: `.next`

## 🔐 Step 3: Environment Variables

Add these in Vercel Project Settings > Environment Variables:

```
DATABASE_URL=postgresql://...
OPENAI_API_KEY=sk-proj-...
HUNTER_API_KEY=...
RESEND_API_KEY=re_...
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
NODE_ENV=production
```

## ✅ Step 4: Deploy

1. Click "Deploy"
2. Wait ~3-5 minutes for build
3. Get your production URL: `https://revora-*.vercel.app`

## 🧪 Step 5: Test Production

```bash
# Test Discovery API
curl -X POST https://revora-*.vercel.app/api/discovery \
  -H "Content-Type: application/json" \
  -d '{"domain":"example.com","businessName":"Test","industryType":"saas"}'

# Test Funnel Generation
curl -X POST https://revora-*.vercel.app/api/funnels/generate \
  -H "Content-Type: application/json" \
  -d '{"businessName":"Test","industryType":"saas","niche":"AI","painPoint":"Low conversion"}'

# Test Outreach
curl -X POST https://revora-*.vercel.app/api/outreach/generate \
  -H "Content-Type: application/json" \
  -d '{"contactName":"John","businessName":"Test","offerHeadline":"Free Consultation","painPoint":"Problem","bonusOffer":"Bonus"}'

# Test Ads
curl -X POST https://revora-*.vercel.app/api/ads/generate \
  -H "Content-Type: application/json" \
  -d '{"businessName":"Test","offer":"Free","painPoint":"Problem","budget":1000,"platform":"facebook"}'

# Test Revenue-Share
curl -X POST https://revora-*.vercel.app/api/revenue-share \
  -H "Content-Type: application/json" \
  -d '{"businessName":"Test","monthlyRevenue":100000,"comissionPercentage":20}'
```
